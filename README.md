# Exercícios de Lógica de Programação

Este repositório contém uma coleção de exercícios de lógica de programação que estou resolvendo para praticar e aprimorar minhas habilidades em programação e raciocínio lógico.

---

## Objetivos

- Praticar lógica de programação básica e intermediária.
- Aprender boas práticas de codificação.
- Melhorar o vocabulário técnico em inglês aplicado a programação.
- Criar uma base de códigos organizada para consultas futuras.

---

## Linguagens utilizadas

- Java (principalmente)

---

## Estrutura do repositório

Cada exercício está em uma pasta ou arquivo separado, nomeado de acordo com o número do exercício ou tema abordado.
